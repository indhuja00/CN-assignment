# Assignment
Assignment 1
## Title
How the Internet Delivers a Web Page
## Objective
To understand how a web page is delivered using the TCP/IP protocol stack, DNS, HTTP, and TCP.
## Solution
Explained the complete process of accessing www.youtube.com, including DNS lookup, HTTP communication, TCP reliability, client–server architecture, cookies, and the communication flow.
## Output
Learned how a browser communicates with a web server to retrieve and display a web page.
## Conclusion
This assignment improved my understanding of application-layer protocols and how they work together to deliver web pages efficiently.
